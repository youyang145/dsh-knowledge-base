# 开发日志

一天一个文件；**同一天有新版本，就开新文件**，不往旧文件里堆。

## 命名

```
YYYY-MM-DD-vX.Y.Z.md
```

- `X.Y.Z` = 当天结束时的项目版本（不是当天开始时的）；
- 同一天多个版本就多个文件，按版本排序读；
- 每个文件开头写清：版本、范围。

## 为什么这么分

- 一天的日志写太长，找东西要翻半天；按版本切开，每篇只讲一个阶段；
- 版本号跟插件/库的版本走，方便和 `决策日志`、GitHub 提交对上；
- 旧文件不回改，新结论写在新的那一天/那一版里。
