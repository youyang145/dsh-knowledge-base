## 七、算法整理员（`kb tidy`）

- **变更检测**：按 `content_hash` 比对上次整理状态（`_tidy/state.json`），跑过的不再报；

- `--apply` 只补「简介为空」的块，标 `editor=algorithm`；已有简介不动；
- 二次运行 0 变更 0 任务，状态生效。

## 八、P1：知识块类型 / 标签 / 目录

- `kind` 八种：concept / howto / troubleshoot / reference / tutorial / decision / code / faq；
- `tags[]`：检索时一起进索引；
- 目录：正文 `##` / `###` 自动抽取（`#` 当块标题、`####` 不抽），**不落库**，明文仍是真源；
- 新建时按类型带骨架（排错=症状/原因/修复；howto=前置/步骤/结果…）；
- 经验块**没有目录**，保持固定卡片；
- CLI：`kb add --kind --tags`、`kb toc <id>`；API 详情返回 `kind/tags/outline`。

## 九、三维索引与交互修复

- 索引页改为领域球 → 块球两层：斐波那契球面 + 每帧投影，文字始终正对人；
- 拖动旋转、惯性、静止自转；点领域进入块层，点块打开详情；
- "点了没反应"：`setPointerCapture` 把 click 抢到容器上，已去掉捕获；
- "往下点跳到最上面"：render 重建 DOM 丢滚动位置，已记住主区/列表滚动；
- 加了玻璃核心与玻璃标签片，解决"字存在感低"。
