## 三、经验块（M1）

作者口述定下的模型：**不是操作记录，是用着用着长出来的判断**。

- **五动作**：套用 / 自创 / 融合 / 推翻 / 跨域派生
- **五计数**：复现 4（开方）、成功 3、使用 2、补充 2、人票 5，+ 手动置顶
- **归属**：按"出生领域"归档；融合经验的出生地 = 解决的那个问题所在领域
- **血缘**：`fused_from` / `derived_from` / `superseded_by` / `refuted_by`
- **孤儿**：知识块删了，经验不连坐，标 `orphaned` 留在领域里

七条验收全过（优先级公式 15.93、融合落物理、派生归零、推翻不进检索、转正置顶、孤儿、冷启动）。

## 四、提议与拍板（M2）

规则：**记账不用问，长经验必须问。**

- `proposals` 表：new / merge / transplant / refute，状态 pending / accepted / rejected / auto_applied
- 三档模式：审核（默认，每天 ≤3、同主题冷却 24h）/ 免审（进小经验区，10 条或 7 天通知）/ 关闭
- 提议卡是人话：判断 + 依据 + 范围 + "跟哪条有重叠"
- 拍板留档：谁、什么时候、改了什么（人改的以人为准）
- 两条护栏：**推翻永远人审**；**人点头即视为验证**（`tier=main`、`status=verified`、`editor=human`）

八条验收全过。
