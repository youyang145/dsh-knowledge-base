## 二十七、面板改成可折叠的"文件夹树"

- 两级都成了文件夹：`示例` → `种子`，`工具` → `GG修改器`，点组头展开/收起，chevron 指示状态；
- 父级显示**聚合条数**（示例 100、工具 6），不再是 0；
- 照 [MDN treeitem 规范](https://developer.mozilla.org/en-US/docs/Web/Accessibility/ARIA/Reference/Roles/treeitem_role) 加了 `role=treeitem` / `role=group`、`aria-expanded`、`tabindex`，Enter/空格可切换；
- sticky 组头保留，展开后可键盘操作。

**外部可借鉴**（查过，不是拍脑袋）：

- MDN treeitem：树的无障碍标准写法（aria-expanded、group、键盘约定）；
- Obsidian / Logseq 的文件树：chevron + 缩进 + 数量徽标 + 粘性分组头，就是现在这套；
- Notion 侧栏：hover 才出现操作按钮，平时只留标题，减少视觉噪音（下一步可借）；
- Salesforce Lightning tree 文档：树节点的选中/展开分离，避免"点一下既筛选又展开"的歧义。

**骨架端到端演示**（`dsh-kb/scripts/demo-e2e.mjs`，临时库）

```
[1] 存一条知识（工具/GG修改器）        → k261101brz0sb
[2] 资料入库：分 3 块 → 全部进「待分区」
[3] 查库：判定"查库" → 命中 GG 那条
[4] 记经验并套用两次                   → used=2 succeeded=2 优先级=10
```

这条链路把骨架的五个关键点串起来了：两级分区、待分区收件箱、查库判定、复用记账、反例警示。每一步都是库的真实函数，不是演示用的假数据。

## 三十五、界面入口：右下角挂件（照小鲸鱼的做法）

DSH 的 client 半端要 React 构建 + 写 profile，路太长；小鲸鱼用的是**宿主注入**：插件注册 `/dsh-kb/widget.js` 路由，再 `webServer.tapIndex` 把 `<script defer>` 塞进页面。照抄这条路线。

**挂件行为**

- 右下角 44px 圆钮（K + 绿点），可拖动，位置记在 localStorage；
- 拖动和点击分开：移动超过 4px 不算点击；
- 点开是 460×560 的小弹窗，iframe 加载面板 `?embed=1`；
- 面板没启动时给"跑 npm run serve"的提示；
- 支持 Esc 关闭、↗ 新标签打开、✕ 收起。

**嵌入模式**（`?embed=1`）

- 隐藏侧栏，列表/详情互斥，单列布局；
- 修了两个"看起来不难"的坑：iframe 没给高度（默认 150px）、面板 `.split` 在嵌入里高度塌成 84px；补了 `.body/main/split` 的 flex 链和 iframe 100% 高度。

**验证**：浏览器里点按钮出弹窗、列表 116 条正常、拖动后位置记住。

**仓库归属**：演示不另开库，放同一个仓库的 `docs/演示.md`——第一个版本还不到"独立产品"的程度，一个库讲一个故事更清楚。
